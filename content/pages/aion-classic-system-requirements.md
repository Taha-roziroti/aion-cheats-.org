# Aion Classic System Requirements

Check your PC before you buy the **ESP and aimbot main plan** or the **Cloud DMA** and **HWID Spoofer** supporting products.

## Main plan (ESP & aimbot)

The partner listing for the main plan includes:

- Windows 10 or Windows 11 (64-bit).
- At least 8 GB RAM.
- A dedicated graphics card.
- HVCI, Core Isolation, TPM, and Secure Boot enabled where listed.
- Stable internet connection.

These requirements apply to the overlay software itself. They do not replace Cloud DMA checks when you use that stack.

## Cloud DMA (supporting product)

Cloud DMA is sold separately from the ESP and aimbot plan.

Typical listed requirements include:

- Windows 10 or Windows 11 with Hyper-V capable edition.
- Intel VT-x or AMD-V enabled in firmware and Windows.
- Minimum 8 GB RAM; 16 GB recommended for the Hyper-V guest.
- Secure Boot and Core Isolation compatible with Hyper-V setup.

See the [Cloud DMA requirements page](/cloud-dma-for-aion-classic/) for GREENWARD, Static Server, and AWS purchases.

## HWID Spoofer (supporting product) {#hwid-spoofer}

HWID Spoofer is a **separate utility**, not bundled with the main ESP and aimbot plan.

Confirm Windows version, driver state, and any vendor notes on the partner listing before checkout. We do not publish a separate feature menu here—verify the live product page.

## Quick checklist

- Windows 10 or Windows 11 64-bit for the main plan.
- Security settings enabled per the partner listing.
- Hyper-V and virtualization documented if you buy Cloud DMA.
- HWID Spoofer purchased only when you need that utility—never assumed in the main plan price.
