# Cloud DMA for Arena Breakout Infinite

A Cloud DMA setup has a few more moving parts than a standard Windows application. The operating system, firmware virtualization setting and Hyper-V configuration all have a role in preparing the required environment.

**Cloud DMA for Arena Breakout Infinite** is listed as the required configuration for full functionality on supported builds. Its setup is built around one Windows PC using a Hyper-V-based virtual environment.

Here's what the configuration involves, which system requirements are listed, and which additional services need to be included when planning the complete setup.

## Cloud DMA for Arena Breakout Infinite: how the setup works

The Cloud DMA product is described as an infrastructure layer that operates on a single gaming PC.

Its installer provisions a Hyper-V-based virtual environment on that machine and completes activation through its service link.

The single-PC arrangement is an important part of the design. The listed configuration does not require a second physical tower, an external DMA box or a separate PCIe DMA card.

Instead, the setup uses the Windows PC and its virtualization capabilities.

## Understanding the single-PC Hyper-V configuration

Hyper-V is Microsoft's virtualization technology. In this configuration, it provides the virtual environment used by the Cloud DMA setup.

The CPU must support hardware virtualization, and the corresponding option must be enabled in the system firmware.

The listed processor virtualization options are:

- Intel VT-x.
- AMD-V.

The Windows installation must also support the Hyper-V role.

Windows Pro, Enterprise and Education editions are recommended for that role. The setup instructions should be checked against the exact Windows edition installed on the PC.

These are the main system-level considerations to review before beginning configuration.

## Windows and hardware requirements

The Cloud DMA listing identifies the following requirements.

| Requirement | Listed specification |
|---|---|
| Operating system | Windows 10 / Windows 11 (64-bit) |
| HVCI | Enabled |
| Core Isolation | Enabled |
| TPM | Enabled |
| Secure Boot | Enabled |
| CPU virtualization | Intel VT-x or AMD-V |
| Memory | 8 GB minimum |
| Recommended memory | 16 GB |
| Internet | Stable broadband |
| Virtualization | Ability to enable Hyper-V |

The operating system edition matters because Hyper-V availability depends on the Windows edition and configuration.

If you're reviewing a PC before starting the setup, check the Windows edition and firmware virtualization setting first.

## Additional services required for Cloud DMA

There are three additional services identified in the Cloud DMA requirements.

| Component | Purchase status |
|---|---|
| GREENWARD | Separate purchase required |
| Static Server | Separate purchase required |
| AWS | Separate purchase required |

These are separate from the Cloud DMA product itself.

One detail worth keeping clear: Static Server and AWS are two different products. Both are required for the listed configuration.

The Cloud DMA price does not include these separate purchases. Their current individual prices should be checked against their respective listings.
