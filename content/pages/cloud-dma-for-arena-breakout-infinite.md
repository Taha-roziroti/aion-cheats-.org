# Cloud DMA for Arena Breakout Infinite

**Cloud DMA for Arena Breakout Infinite** is the Hyper-V infrastructure layer the vendor lists for full ABI functionality on supported builds. One gaming PC hosts the virtual environment—no second tower, external DMA box, or PCIe card appears in the published single-PC design.

## What you are configuring

The installer provisions Hyper-V on that machine and activates through the vendor service link. You will need firmware virtualization (Intel VT-x or AMD-V), a 64-bit Windows 10 or 11 build with HVCI, Core Isolation, TPM, and Secure Boot enabled, plus the RAM and storage figures on the live listing. Windows Pro, Enterprise, or Education is recommended so the Hyper-V role can install cleanly.

Walk through the [Cloud DMA installation guide](/guides/cloud-dma-setup/) after checkout and before you pair Cloud DMA with the main cheat stack.

## Pricing and extra services

Cloud DMA is listed at **$50 lifetime** on its own product page. GREENWARD, Static Server, and AWS are called out as separate purchases—Static Server and AWS are not interchangeable. Total your cart against current shop prices before you budget the full environment.

Main ABI modules (ESP, aimbot, etc.) remain on the [ABI plan pricing sheet](/arena-breakout-infinite-cheats-pricing/).

[**View Cloud DMA checkout**](/go/cloud-dma/)

Activation emails and service links expire or rotate—save copies offline the same way you would for any infrastructure credential. If you rebuild the host image, expect to re-run installer steps and re-validate Hyper-V health before launching the game guest again.

## Questions

**Why is Cloud DMA required?**  
The vendor marks it as required for full functionality on supported builds.

**Does it need a second PC or hardware DMA?**  
The published design targets one Windows PC with Hyper-V, not an external DMA card.

**Which Windows editions work?**  
64-bit Windows 10/11 with virtualization-friendly editions (Pro/Enterprise/Education recommended).

**What else must I buy?**  
GREENWARD, Static Server, and AWS are listed separately from the $50 license.

**How much is the license?**  
$50 lifetime on the current Cloud DMA listing.
