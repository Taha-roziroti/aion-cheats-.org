# Arena Breakout Infinite system requirements

Use a 64-bit edition of Windows 10 or Windows 11 with current patches installed. Confirm your Arena Breakout Infinite client matches the supported build before checkout.

## Hardware checklist

- 16 GB RAM minimum; 32 GB recommended when Cloud DMA and the cheat stack run together  
- Virtualization enabled in firmware/BIOS for Hyper-V based Cloud DMA  
- Dedicated GPU that meets the game’s published requirements
